# Проверка в настоящих Figma и Resolve

Выполняйте на копии композиции. Запишите ОС, архитектуру, версию и редакцию Resolve,
версию Figma и номер коммита. Прохождение CI не заменяет эти шаги.

1. На чистом профиле установите готовый пакет без Node.js/Swift. На Windows Python
   отдельно не требуется; на Mac требуется Python 3.9+. Перезапустите Resolve.
2. Убедитесь, что три Lua-команды появились в Workspace → Scripts. Повторная
   установка должна восстановить отсутствующий модуль.
3. Импортируйте manifest в Figma Desktop. Неверный код сопряжения должен быть
   отклонён; правильный — подключить плагин. После перезапуска посредника
   сохранённый токен должен работать.
4. Передайте прямоугольник со сплошной заливкой без обводки. Выполните Connection
   Test и Receive. Проверьте масштаб, положение, прозрачность и скругление.
5. Добавьте эллипс, текст со шрифтом, установленным на этом компьютере, и изображение.
   Сравните текст, цвет и изображение. Проверьте Loader после закрытия и повторного
   открытия проекта. Проверьте появление предупреждения о недостающем шрифте.
6. Проверьте пути с пробелами и кириллицей. Сохраните проект, перезапустите компьютер
   и убедитесь, что изображения остаются доступны.
7. Обводка/многоугольник, требующие experimental sRender, должны дать понятное
   сообщение и не размещаться в композиции. Не отключайте защиту ради теста.
8. Повторный Receive вставляет новый граф; анимация старого графа автоматически
   не переносится. Убедитесь, что Undo отменяет вставку.
9. Отдельно проверьте проекты без управления цветом и поддерживаемые managed
   режимы. Сравните итоговый кадр; не объявляйте визуальное соответствие по логам.
10. Закройте посредник: новый Receive должен сообщить об отсутствии соединения.

Критерий релиза: нет падений Resolve, изображения сохраняются после перезапуска,
ошибки не замалчиваются, базовые узлы редактируются, README соответствует результатам.
Отдельные строки матрицы нужны для Windows/macOS и Free/Studio. Непроверенные
сочетания следует оставлять неподтверждёнными.
