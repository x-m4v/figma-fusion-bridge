# Figma Fusion Bridge

[English](README.md) · [Результаты проверок](docs/VALIDATION.md) · [Публикация на GitHub](docs/PUBLISHING.ru.md)

Независимый экспериментальный инструмент для переноса выделения из Figma в
редактируемую композицию Fusion в DaVinci Resolve. Лицензия MIT.

Это **три части**: плагин Figma, локальное приложение-посредник и команды Lua в
Resolve с обработчиком на Python. Figma, посредник и Resolve работают на одном
компьютере. Передача идёт через локальный HTTP с кодом сопряжения и токеном;
облачный сервис передачи не используется.

## Что проверено

| Платформа | Статус | Требования |
|---|---|---|
| macOS | Приложение собирается; автоматические проверки проходят. Полный перенос Figma → Resolve ещё требует ручной проверки. | macOS 14+, Apple Silicon, Python 3.9+ |
| Windows | Сборка EXE, установщик, HTTP/GUI и запуск через LuaJIT проверены на Windows x64. Полная проверка в Resolve ещё предстоит. | Windows 10/11 x64; в готовый пакет включён Python |

Для установки плагина нужен **Figma Desktop**. Совместимость конкретной версии
Resolve и редакций Free/Studio проверяется отдельно: тесты обработчика не
доказывают, что все узлы правильно отрисуются в приложении.

## Простая установка

Скачайте пакет своей системы из [предварительного релиза](https://github.com/x-m4v/figma-fusion-bridge/releases/tag/v0.1.0-preview.1).
Кнопка **Code → Download ZIP** скачивает исходники, а не готовую программу.
После успешной сборки тестовые пакеты доступны также в
**Actions → Check and build → Artifacts**.

### macOS

1. Распакуйте архив macOS ARM64 в постоянную папку.
2. Если `python3` отсутствует, установите Python 3.9+. Для готового пакета Node.js и Swift не нужны.
3. Запустите `Install.command`: он установит скрипты для вашего пользователя и откроет приложение. Альтернатива — выполнить `python3 bridge-python/app.py --install` в распакованной папке и открыть приложение.
4. Перезапустите Resolve. Посредник должен оставаться запущенным в строке меню.

Приложение имеет локальную подпись, но **не прошло нотариализацию Apple**.
Загруженный экземпляр может блокироваться Gatekeeper. Если доверяете источнику,
разрешите запуск через настройки конфиденциальности и безопасности macOS.
Не отключайте Gatekeeper целиком. Для распространения без этого предупреждения
нужны Developer ID и нотариализация.

### Windows

1. Распакуйте архив Windows x64 в постоянную папку. Не отделяйте EXE от папки `_internal`.
2. Запустите `Install.cmd` либо откройте `FigmaFusionBridge/FigmaFusionBridge.exe`
   и нажмите **Install / repair Resolve scripts**. Права администратора не нужны.
3. Перезапустите Resolve. Оставьте окно посредника открытым.

EXE пока не подписан сертификатом. Не отключайте антивирус ради установки.
При перемещении программы повторите установку скриптов. Пробелы и кириллица в
путях поддерживаются. Windows-команда использует LuaJIT и Unicode API запуска
процессов; командная оболочка не интерпретирует пути.

### Figma и первый перенос — обе системы

1. В Figma Desktop: **Plugins → Development → Import plugin from manifest**.
2. Выберите `figma-plugin/manifest.json` из готового пакета.
3. Запустите плагин и введите код сопряжения из приложения-посредника.
4. Для первого теста выделите простой прямоугольник со сплошной заливкой **без обводки** и нажмите **Send to Fusion**.
5. Откройте тестовую композицию на странице Fusion в Resolve.
6. Выполните **Workspace → Scripts → Figma Fusion Bridge - Connection Test**, затем **Figma Fusion Bridge - Receive**.
7. Проверьте узлы и изображение перед использованием в рабочих проектах.

## Ограничения текущей версии

- Receive при каждом запуске вставляет **новый граф**. Повторная синхронизация
  с автоматическим сохранением существующей анимации в этой команде не реализована.
- **Pull Figma Selection не реализован** на стороне посредника. Используйте Send to Fusion.
- Live Sync в Figma обновляет доступную передачу, но не обновляет композицию Resolve автоматически.
- Безопасный режим Receive переводит сплошные прямоугольники и эллипсы в маски.
  Некоторые обводки и многоугольники требуют экспериментального `sRender` и блокируются.
  Старый пример pricing-card предназначен для проверки обработчика и может быть
  заблокирован при Receive. Для проверки HTTP и CLI добавлен `examples/starter-transfer.json`.
- Размытие, режимы наложения, сглаживание углов и типографика могут отличаться.
  Цвет необходимо проверять визуально в своей версии Resolve.
- Шрифты не переносятся: установите их отдельно при наличии прав.
- Автотесты не заменяют проверку изображения и стабильности Resolve.

## Установка из исходников

Нужны Node.js 24 и Python; для macOS также Xcode Command Line Tools.

```bash
# macOS
bash scripts/install.sh
```

```powershell
# Windows: Python 3.11 x64 с py launcher и Node.js 24
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/install-windows.ps1
```

Просмотрите установщик перед запуском. Путь к плагину из исходников:
`packages/figma-plugin/manifest.json`. Команды сборки и проверки приведены в
[английском README](README.md#building-from-source).

## Данные и удаление

Данные macOS: `~/Library/Application Support/FigmaFusionBridge`.
Данные Windows: `%LOCALAPPDATA%/FigmaFusionBridge`.
Команды Resolve в Windows:
`%APPDATA%/Blackmagic Design/DaVinci Resolve/Support/Fusion/Scripts`.

Для удаления уберите только три команды `Figma Fusion Bridge - *.lua` из `Comp`
и `Utility`, затем приложение. Не удаляйте `Assets` и `BridgeAssets`, пока
композиции используют сохранённые изображения. Не публикуйте `session.json`,
`credentials.json`, локальные кэши и реальные выгрузки дизайнов.
